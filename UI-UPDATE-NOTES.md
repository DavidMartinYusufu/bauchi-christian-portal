# UI polish update

This update preserves the existing section order, content, colours and membership form integration while refining the statistics and LGA cards.

- Replaced the duplicated 20-LGA stat with a distinct 211-wards total (sum of the ward counts in the supplied LGA data).
- Increased the prominence and contrast of the main figures.
- Improved LGA card number badges and displayed ward counts as a distinct label.
- Repaired the dropdown label markup and restored a clear chevron indicator with open/closed state styling.
- Kept the responsive LGA card grid at 3 columns on desktop, 2 on medium screens and 1 on small screens.
